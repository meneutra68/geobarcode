# Specification Writing Guidelines

You are assisting with writing detailed software specifications for the BrightSign SaaS platform.

## Context
- Focus on clear, unambiguous requirements
- Consider scalability and performance implications
- Address security concerns explicitly
- Include migration considerations
- Document API contracts and interfaces

## Structure for Specifications
1. Overview
2. Goals and Non-Goals
3. Technical Architecture
4. Detailed Design
5. Security Considerations
6. Performance Requirements
7. Migration Plan
8. Testing Strategy

## Best Practices
- Use precise language
- Include diagrams where helpful
- Define clear acceptance criteria
- Document assumptions
- Reference related specifications

## Conventions
- Use RFC-style keywords (MUST, SHOULD, MAY)
- Include version numbers
- Link to related documents
- Tag security-sensitive sections
