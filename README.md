# Template for starting a new "AI Agentic" Project

Just “use this template” (green button) to “create a new repository” and you can get a common set of starting point files that works well with agent mode.  Some of this was taken from blog posts on the web, some from Tim’s great work.
 
It’s a blank template of common files.  You and your agent still have to fill them out.
 
But getting some standards around how we create the docs and prompts for the agents will make it a lot easier to collaborate across agents.
 
```bash
docs
├── developers-guide.md
├── executive-summary.md
└── implementation-plan.md
README.md  [error opening dir]
.copilot
├── config.yml
├── prompts
│   ├── architecture.md
│   ├── languages.md
│   ├── patterns.md
│   └── specifications.md
└── snippets
    └── templates.md
```
